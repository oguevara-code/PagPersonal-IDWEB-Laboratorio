# ZonaBike

## URL del proyecto
https://github.com/omar-guevara/zonabike

## Descripción
ZonaBike es una página web de venta de bicicletas y accesorios de las marcas Trek y Specialized. La tienda ofrece una variedad de categorías como bicicletas montañeras, de ruta, urbanas y para niños, además de cascos e indumentaria para ciclismo. El sistema permite visualizar productos por categoría, ver el detalle de cada producto, agregar artículos a un carrito de compras, permite mandar un mensaje en la parte de contacto, y tambiénn se puede iniciar sesión y registrarse.
